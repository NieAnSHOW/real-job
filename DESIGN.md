# Real Job interface foundation

This is a restrained Operate surface for a browser extension, not a marketing page. Initial defaults are implementation choices, not a separate user-approved visual brand.

Use a warm near-white background, dark readable text and a muted deep teal action color. Compact masthead, clear task heading, one primary action, flat divided sections and sufficient space between groups. Use system Chinese-compatible sans-serif fonts packaged/system only; no external fonts, imagery, tracking or decorative animations. Rounded controls, visible keyboard focus, clear inline success/errors and text alongside status colors.

Sidepanel must fit 320px without horizontal scrolling; settings use a readable centered column and stack on narrow widths. All functionality/statuses reflect actual implementation: no demo ratings, fabricated metrics or fake connection checks. LingDT unavailable state explains the unverified official gateway. API links open official sites safely. Password inputs are never repopulated from saved secrets.
